## RU SIMPLE HELP

Минималистичный язык разметки документов справки на русском языке.

Позволяет писать справку на русском языке без переключения раскладки клавиатуры.

Rust-библиотека: документ компилируется в один `html` файл со встроенным минимальным стилем.

Расширение файлов: `.rush`.


## Синтаксис

### Общие правила

- Файл читается в кодировке UTF-8. UTF-8 BOM (`U+FEFF`) в начале файла игнорируется.
- Конец строки: `\n` или `\r\n`.
- Элементы разметки начинаются с `\` и тега.
- **Пустая строка** -- строка из одних пробелов и табуляций или без символов.
- **Блочный элемент** занимает одну или несколько целых строк. **Строчный (inline) элемент** находится внутри текста.
- **Парный блок** (комментарий, формула, код) и **тройной блок** (таблица) открываются тегом в начале строки и длятся до закрывающего тега на отдельной строке. Пустые строки внутри не разделяют абзацы.
- **Незакрытый парный блок** длится до первой пустой строки или конца файла.
- **Незакрытый тройной блок** (меньше трёх тегов `\№`) разбирается как обычный текст.

#### Экранирование

- Экранирующий символ `_` действует только на спецсимволы: `\` `_` `:` `;` `-` `=` `!` `%` `(` `)` `/`.
- `_` перед спецсимволом опускается, спецсимвол выводится буквально.
- Перед другим символом или концом строки `_` выводится как есть.
- `__` -- символ `_`.
- `_\` -- символ `\`, после которого не начинается элемент разметки.
- Примеры: `\:10_:30:` -- жирный текст `10:30`; `snake_case` -- текст `snake_case`; `a__:` -- текст `a_:`; `_\:` -- текст `\:`.
- Внутри формулы, кода и параметров изображения экранирование не действует.

#### Именованные элементы

Формула, код, таблица и изображение имеют имя (подпись) и нумеруются по порядку, отдельно для каждого вида.

Имя `0` делает элемент **анонимным**: без подписи и без номера.

```
\$0
<LATEX ФОРМУЛА>
\$

\//0
<КОД>
\//

\№0
...

\(<ПУТЬ К ИЗОБРАЖЕНИЮ>, 0)
```


### Блочные элементы

#### Абзац

Абзацы разделяются одной или несколькими пустыми строками.

Блочный элемент внутри абзаца делит его на `абзац`, `блочный элемент`, `абзац`. Пустые части отбрасываются.

#### Заголовок

```
\+ <ТЕКСТ>
\++ <ТЕКСТ>
...
\+++++ <ТЕКСТ>
```

- `\`, затем `N` символов `+` и обязательный пробел.
- `N` -- уровень от 1 до 5, больше пяти считается пятым.
- Текст заголовка -- остаток строки, `+` внутри него не имеют значения: `\++ Язык C++`.
- Заголовок -- отдельный блок.

#### Список

```
\. <ПУНКТ>
\ . <ПУНКТ ВТОРОГО УРОВНЯ>
\  1 <ПУНКТ ТРЕТЬЕГО УРОВНЯ>
\  1 <ПУНКТ ТРЕТЬЕГО УРОВНЯ>
\. <ПУНКТ>

\1 <ПУНКТ>
\ 1 <ПУНКТ ВТОРОГО УРОВНЯ>
```

- `\.` -- пункт ненумерованного списка.
- `\1` -- пункт нумерованного списка. Нумерация автоматическая.
- Пробелы между `\` и маркером задают уровень вложенности: `1 + <число пробелов>`.
- После маркера всегда идёт пробел.
- Список -- подряд идущие пункты, строка без маркера его завершает.
- В одном списке могут смешиваться пункты `\.` и `\1`.

#### Изображение

```
\(<ПУТЬ К ИЗОБРАЖЕНИЮ>, <ПОДПИСЬ>, <МАСШТАБ>)

\(<ПУТЬ К ИЗОБРАЖЕНИЮ>, <ПОДПИСЬ>)
```

- Параметры разделяются запятой. Пробелы вокруг параметров обрезаются.
- `<ПУТЬ К ИЗОБРАЖЕНИЮ>` -- обязательный, относительно файла `.rush`.
- `<ПОДПИСЬ>` -- обязательный, `0` -- анонимное изображение.
- `<МАСШТАБ>` -- необязательный, процент от исходного размера: `120` -- увеличить в 1.2 раза.
- Изображение -- блочный элемент.

#### Сноска

```
\**N <ТЕКСТ>
```

- Отдельный блок, всегда с новой строки.
- `N` -- целое неотрицательное число, текст сноски -- остаток строки после пробела.
- `N = 0` -- анонимная сноска без ссылок, таких может быть сколько угодно.
- Для `N > 0` повторные определения с тем же `N` отбрасываются.
- Сноска выводится там, где написана.
- Ссылка на сноску -- строчный элемент `\*N`.

#### Комментарий

```
\"
<СОДЕРЖИМОЕ>
\"
```

- Отдельный абзац, выделенный фоном и цветом.
- Может содержать любые строчные элементы.
- Первая же строка `\"` закрывает комментарий, вложенных комментариев нет.

#### Формула

```
\$<ИМЯ ФОРМУЛЫ>
<LATEX ФОРМУЛА>
\$
```

- Содержимое не разбирается и передаётся как LaTeX.
- Единственный элемент, требующий латинской раскладки.

#### Код

```
\//<ИМЯ ЛИСТИНГА>
fn foo(bar: i32) -> i32 {
    bar * 42
}
\//
```

- Содержимое не разбирается, пробелы и пустые строки сохраняются.

#### Таблица

```
\№<ИМЯ ТАБЛИЦЫ>
/ Заголовок 1 / Заголовок 2 / Заголовок 3 / Заголовок 4 /
/ Подзаголовок 1 / Подзаголовок 2 / Подзаголовок 3 / Подзаголовок 4 /
\№ Л / Ц / П / Ц /
/ Ячейка / Ячейка / Ячейка / Ячейка /
/ Ячейка склеенная по горизонтали на две других / \+ / \+ / Ячейка /
/ Ячейка склеенная с нижней / Ячейка / Ячейка / Ячейка /
/ \= / Ячейка / Ячейка / Ячейка /
/ Ячейка / Ячейка склеенная из 4 / \+ / Ячейка /
/ Ячейка / \= / \+= / Ячейка /
\№
```

Таблица содержит ровно три тега `\№`, каждый в начале строки:

1. **Первый `\№`** -- начало таблицы, после него пишется имя.
2. **Второй `\№`** -- разделитель: выше хотя бы одна строка заголовков, ниже содержимое. После него можно указать выравнивание столбцов: `Л` -- влево, `Ц` -- по центру, `П` -- вправо (по умолчанию по центру).
3. **Третий `\№`** -- конец таблицы.

Число столбцов равно наибольшему числу ячеек в строках заголовка, склеивающие ячейки тоже считаются.

- Короткие строки дополняются справа пустыми ячейками.
- Длинные строки обрезаются справа.

Выравнивание:

- `i`-е выравнивание применяется к `i`-му столбцу.
- Столбцы без выравнивания -- по центру.
- Лишние выравнивания игнорируются.

Строки таблицы:

- Строка таблицы начинается и заканчивается `/`, ячейки разделяются `/`.
- `\+` -- склеить ячейку с левой.
- `\=` -- склеить ячейку с верхней.
- Ячейка склеивающая, только если без пробелов по краям она равна `\+`, `\=` или `\+=`. Иначе `\=` -- начало подчёркнутого текста.
- `\+=` -- склеить ячейку с верхней и левой.
- Текст склеенной ячейки пишется в левую верхнюю ячейку.


### Строчные элементы

- Строчные элементы вкладываются друг в друга, в том числе в элементы того же вида.
- Закрывающий символ закрывает последний открытый элемент своего вида. Незакрытые элементы внутри него невалидны: тег опускается, текст остаётся.
  - `\:a \:b: c:` -- жирный текст `a`, внутри которого жирный `b`, затем ` c`.
  - `\:a \;b: c;` -- жирный текст `a b` (невалидное начало курсива `\;` опускается), затем обычный текст ` c;`.
- Конец строки закрывает все строчные элементы.

#### Форматирование текста

| Синтаксис          | Результат             |
|--------------------|-----------------------|
| `\:<ТЕКСТ>:`       | жирный текст          |
| `\;<ТЕКСТ>;`       | курсивный текст       |
| `\-<ТЕКСТ>-`       | зачёркнутый текст     |
| `\=<ТЕКСТ>=`       | подчёркнутый текст    |
| `\!<ТЕКСТ>!`       | моноширинный текст    |
| `\<ЦВЕТ>%<ТЕКСТ>%` | текст цвета `<ЦВЕТ>`  |

`<ЦВЕТ>` задаётся одним из способов:

- HEX: `#` и 6 шестнадцатеричных цифр: `#1b2b20`.
- HEX в русской нотации: `Ц` и 6 цифр, где `a`=`а` `b`=`б` `c`=`в` `d`=`г` `e`=`д` `f`=`е`: `ц1б2б20`. Регистр не важен.
- RGB: 9 цифр, по три на канал: `255103020`.
- Константа:

| Константа | Цвет        |
|-----------|-------------|
| `КРАС`    | красный     |
| `ОРАН`    | оранжевый   |
| `ЖЁЛ`     | жёлтый      |
| `ЗЕЛ`     | зелёный     |
| `ГОЛ`     | голубой     |
| `СИН`     | синий       |
| `ФИОЛ`    | фиолетовый  |
| `РОЗ`     | розовый     |
| `КОР`     | коричневый  |
| `ЛИМ`     | лимонный    |
| `САЛ`     | салатовый   |
| `БЕР`     | бирюзовый   |
| `ЛАЗ`     | лазуритовый |
| `ФУК`     | фуксия      |
| `БЕЛ`     | белый       |
| `ЧЁРН`    | чёрный      |

#### Ссылка

```
\,<ЦЕЛЬ>(<ТЕКСТ>)
```

- `<ЦЕЛЬ>` обязательна.
- Внутренняя и внешняя ссылки записываются одинаково.
- Если `<ЦЕЛЬ>` -- один из компилируемых документов `.rush`, ссылка внутренняя, иначе внешняя (URL).
- Расширение `.rush` можно опускать: `\,справка(текст)` и `\,справка.rush(текст)` равнозначны.

#### Ссылка на сноску

```
\*N
```

- Ссылка на сноску `\**N` этого документа, `N` -- целое положительное число.
- На одну сноску может быть сколько угодно ссылок.
- Ссылка на несуществующую сноску выводится без цели перехода.
- Ссылка заканчивается вместе с числом: `баренцово\*12море` и `война\*12 1912 года` ссылаются на сноску 12.

#### Ссылка на элемент
```
\*ф"..."
\*т"..."
\*р"..."
\*л"..."
```

- Раскрывается в номер элемента по имени: `ф` -- формула, `т` -- таблица, `р` -- рисунок, `л` -- листинг.
- Разбор ссылки кончается `"`.
- Пример: `\*р-Пример` раскроется в `2`, если `Пример` -- подпись рисунка 2.
- После `"` пишется имя, при одинаковых именах берётся первое вхождение.


### Вложенность элементов

| Элемент               | Может содержать                            |
|-----------------------|--------------------------------------------|
| Абзац, пункт списка, ячейка таблицы, заголовок, текст сноски, комментарий | строчные элементы |
| Строчный элемент      | строчные элементы                          |
| Формула, код          | ничего (содержимое не разбирается)         |
